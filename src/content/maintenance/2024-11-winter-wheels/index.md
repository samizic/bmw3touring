The 19″ summer wheels with their low-profile tyres aren't made for snow, so the car got a
dedicated **winter set**.

## The set

- **Wheels:** 18″ BMW **Style 780** in a **square setup**: the same size on all four corners
  instead of the staggered 225/255 summer setup. That means the wheels can be rotated front to
  back, so the tyres wear evenly.
- **Tyres:** **Michelin Pilot Alpin 5**, **225/45 R18 95V XL**, a performance winter tyre with
  the 3PMSF snowflake mark.

The smaller wheel and taller sidewall (45 instead of 40/35 profile) also make the ride more
comfortable and protect the rims from potholes and kerbs in winter.

## Seasonal swap

| | Summer | Winter |
|---|---|---|
| Wheels | 19″ Style 793 (staggered) | 18″ Style 780 (square) |
| Front tyres | 225/40 R19 | 225/45 R18 |
| Rear tyres | 255/35 R19 | 225/45 R18 |

Fit the winter set when temperatures drop under about 7 °C, and swap back in spring. After each
swap, re-torque the wheel bolts after the first 50–100 km and reset the tyre pressure monitor
(iDrive → Vehicle → Tyre pressure monitor → Reset).
